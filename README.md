# Personal Expense Tracker

A Django web app for tracking expenses and managing monthly budgets by category.

## Features

- Record expenses with a title, amount, category, date, and optional description.
- Set a monthly budget for each spending category.
- View total spending, remaining budget, and transaction count on the dashboard.
- See which categories are approaching or exceeding their budget.

## Built with

Python, Django, SQLite, JavaScript, Bootstrap, and CSS.
